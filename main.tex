\begin{frame}[t]{Existing Approaches for LLM Text Detection}
    \begin{itemize}
        \item Retrieval-based detection
            \begin{itemize}
                \item Keeping a growing record of all generated texts and checking against it for matches.
                \item Requires scale and coordination, and raises privacy concerns.
            \end{itemize}
        \item Post hoc detection
            \begin{itemize}
                \item Using the statistical features of text or training a ML-based classifier.
                \item Computationally expensive; inconsistent performance (especially out-of-domain).
            \end{itemize}
        \item Watermarking
            \begin{itemize}
                \item Marking the generated text in some way so that it can subsequently be identified.
                \item Three approaches:
                \begin{itemize}
                    \item During generation. \hspace{50pt} \focus{$\rightarrow$ This paper}.
                    \item Editing already generated text.
                    \item Altering LLM training data.
                \end{itemize}
                \item Often involves a quality (of generated texts) and effect (of detection) trade-off.
            \end{itemize}
    \end{itemize}

\end{frame}

\begin{frame}[t]{Watermarking -- Tournament Sampling}
    General principle: select a token from the LLM distribution that is likely to score higher under some random watermarking functions.

    \focus{Tournament Sampling}: achieve the above using a tournament-like process.

    \focus{Watermarking function}: $g_l(x_t, r_t)$, where $x_t$ is a candidate token, and $r_t$ is a random seed.

    \begin{figure}
        \centering
        \includegraphics[width=0.6\textwidth]{figs/method_tournament_sampling.png}
    \end{figure}

    Larger $m$ $\rightarrow$ better detectability, but it does not increase indefinitely. They use $m = 30$.
\end{frame}

\begin{frame}[t]{Watermarking detection}
    \begin{align*}
        \mathrm{Score}(x) = \frac{1}{mT} \sum_{t=1}^T \sum_{l=1}^m g_l(x_t, r_t) \;.
    \end{align*}
    
    Intuition: $\mathrm{Score}(x)$ takes higher values for a watermarked sequence.
    
    \begin{itemize}
        \item Example: $g_l(x, r) = \ind\{u_l(x, r) > 0.5\}$, where $u_l(x, r)$ is a pseudo-random function generating values in $[0, 1]$.

    \end{itemize}

\begin{frame}[t]{Guarantees and detection}
    % Non-distortion: token, single-sequence, and multiple-sequence levels.
    % Repeated-context masking and a short proof sketch.
    % Watermark score, null hypothesis, thresholds, and abstention.
    % Detection power as a function of text length and entropy.

    \begin{figure}
        \centering
        \includegraphics[width=0.8\textwidth]{figs/method_non_distort.png}
    \end{figure}
    Notation: 
    \begin{itemize}
        \item $V = $ set of candidate tokens (vocabulary).
        \item $\Delta V = \text{probability simplex over $V$} = \{ p: V \rightarrow [0, 1] \mid \sum_{x \in V} p(x) = 1 \}$. 
        \item $\mathcal{R} = $ set of possible random seeds.
    \end{itemize}

    \xl{highlight box}
    In words: A sampling algorithm is non-distortionary if in expectation the distribution on the next token is identical before and after watermarking.

    \focus{Strong non-distortion}: the above is extended for \textbf{sequences} of text.

\end{frame}
